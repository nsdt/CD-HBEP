# CD-HBEP comparison app

`index.html` is a self-contained comparison application for Certification-Driven Hermite Beam-Energy Projection (CD-HBEP). It has no build step, server, or network dependency. Open it directly in a current Chrome, Edge, or Firefox browser.

## Data and methods

Enter one `x, y` pair per line with strictly increasing `x`, or load one of the built-in examples. The data panel also samples any of the six exact reference functions from the manuscript at a selected value of `N` on uniform or deterministic nonuniform knots. Here, `N` is the number of data values supplied to each interpolant; it is not the drawing resolution. The exact function is drawn independently, and the curve-drawing control determines only the number of line segments on the screen. The app compares linear interpolation, NC-spline, Akima, Makima, PCHIP, Hyman-filtered spline, the final DEH cubic algorithm, the Han–Guo minimal derivative oscillation method (HG-MDO), thesis-style rod FEM interpolation, and CD-HBEP. The rod FEM option is a historical reconstruction model included to show the design lineage of CD-HBEP; it is not one of the manuscript's principal comparison methods.

HG-MDO implements Eq. (3) of Han and Guo (2018). It minimizes the integrated squared difference between the derivative of the cubic Hermite interpolant and the derivative of the piecewise-linear interpolant. The resulting strictly diagonally dominant tridiagonal system handles uniform and nonuniform knots and requires no tuning parameter. The method does not impose a shape constraint, so some data can produce overshoot or reverse motion even when the objective is minimized. The deterministic manuscript artifacts include this method as a global value-only optimization baseline.

DEH-CM implements the final cubic algorithm in Dougherty, Edelman, and Hyman (1989), including the three parabolic slopes, the `C = 1.5` relaxation, the final interior bound, and the endpoint rule. Natural-cubic slopes are the initial derivative estimates.

CD-HBEP projects the natural-spline slope vector in the Hermite beam-energy metric and activates finite slope bounds only after exact interval certification. The reference configuration contains twelve fixed empirical activation constants. CD-HBEP applies the same values to every data set and requires no case-specific or user tuning. It does not impose one global shape-preservation condition. Its core guards are:

- Bezier-envelope and material-handle bounds.
- The sharp Hermite monotonicity box, activated by integrated reverse motion.
- A chord-side guard on locally convex or concave data.

The chord-side classifier has no minimum-run-length setting. It examines all available adjacent secant-slope differences; every difference must be nonzero and have one sign. Endpoint intervals have one available difference. Envelope and monotonicity bounds are primary. The implementation assembles all secondary chord-side candidates simultaneously and computes the smallest common factor `lambda >= 1` that leaves every coordinate box nonempty. The analytical bound is `lambda <= max(1, 1 / (3 * sideLocalFraction))`; the default `sideLocalFraction = 0.20` gives `lambda <= 5/3`. The app reports the analytical factor, its rounding-safe applied value, and each `nominal -> effective` slack. This simultaneous rule is independent of interval traversal order and remains equivariant under horizontal reflection. The seeded benchmark report also includes the number of constructions and active interval bounds that required relaxation.

The fixed activation controls follow the manuscript terminology. Scale fractions are named by their guard and their reference scale, such as `envelopeLocalFraction` and `sideRangeFraction`. Isolated-reversal modifiers and the Bezier-handle multiplier have separate names because they alter different tests. The chord-side defaults are `(sideLocalFraction, sideRangeFraction) = (0.20, 0.07)`, denoted by `(omega_side^loc, omega_side^rng)` in the manuscript. The CD-HBEP panel exposes all twelve empirical activation constants and permits their values to be changed for inspection and reproducibility. The manuscript results retain the displayed defaults across every case.

The deterministic parameter-validation profile freezes those twelve displayed values as the reference configuration. A digitally shifted 12-dimensional Sobol design examines 1024 configurations over multiplicative intervals from 0.5 to 2 times every reference value. A separate 256-configuration design examines the 0.9--1.1 neighborhood. The calibration suite contains 200 seeded stress cases and 24 exact-function configurations. The independent hold-out changes the random seed, contains 500 stress cases, and introduces four exact functions and different sample counts. Accuracy, upper-tail shape diagnostics, and dimensionless beam intervention remain separate Pareto objectives. Numerical certificates are mandatory. The complete protocol is implemented by `scripts/validate_activation_parameters.cjs`; its seeds, functions, domains, and reference values are defined in `index.html`.

Before constructing the objective or any certificate, CD-HBEP maps `x` to `(x - x0)/(xn - x0)` and maps nonconstant `y` to `(y - y0)/(max(y) - min(y))`. A constant ordinate sequence follows an explicit zero-signal branch. Slopes and reported chord-side slack are restored to the supplied units. All fixed numerical thresholds therefore operate on dimensionless internal data.

The CD-HBEP implementation stores the objective in three bands and ordinarily solves free active-set blocks with an in-place Thomas algorithm. A result from this fast path is accepted only after primal and normalized KKT residual checks. The KKT residual is divided by `max(1, ||Q theta||_inf, ||r||_inf)`. If the first block representation reaches `4N + 10` sweeps without a residual certificate, the app applies positive diagonal equilibration and retries the capped block path. If the equilibrated block representation also lacks a certificate, a Pang–Han parametric principal pivoting fallback solves the equilibrated QP. The fallback substitutes equality variables, eliminates completely unrestricted variables by path Schur complements, and solves the reduced tridiagonal box QP in `O(N^2)` worst-case work. Combining this bound with the finite outer activation limit gives `O(n^3)` worst-case work for the complete method. Natural and not-a-knot spline baselines also employ banded formulations, so the timing benchmark can process `N = 10, 100, 1000, 5000, 10000, 50000, 100000` data points without constructing dense spline matrices.

## Metrics and benchmarks

The displayed manuscript diagnostics are defined for one cubic Hermite segment per data interval. They are therefore shown as unavailable for linear and refined-mesh FEM curves instead of estimating fictitious Hermite slopes. The manuscript comparison and deterministic exporters follow the Introduction order: NC-spline, Makima, PCHIP, HF-spline, DEH-CM, HG-MDO, and CD-HBEP. The six shape diagnostics are dimensionless. Chord deviations are normalized by the data ranges, and curve-length excess is computed after independently normalizing the horizontal and vertical coordinates. Smaller values indicate less of the measured behavior rather than greater interpolation accuracy.

The manuscript accuracy benchmark samples six known functions: a smooth oscillation, a smooth lower arc with a compact central lift, a localized peak, a `C2` multi-level plateau function, a monotone sigmoid, and a steep exponential boundary layer. It evaluates normalized maximum and RMS errors on uniform and deterministic nonuniform knots for `N = 10, 30, 60, 100, 200, 400, 800`. These reference-function errors assess approximation accuracy. The chord- and length-based diagnostics have a separate role: they describe behavior for discrete data whose continuous source is unknown.

Benchmark failures are counted and reported; they are never silently folded into a mean. The manuscript exporter treats any method failure as a failed run. It also records the QP solves, block-path sweeps, equilibration retries, PPPA calls, Pang–Han pivots, and maximum normalized and raw primal and KKT residuals for every CD-HBEP construction.

Random `plateau` cases use three or four exact constant runs. Every run has at least two samples, the heights are distinct, and their order contains both an upward and a downward change. They are therefore multi-level plateau tests rather than monotone logistic curves. The fifth random class independently generates one member of each of the four base classes, centers and range-normalizes the components, and blends them according to twelve jittered profiles. The profiles cover balanced mixtures, dominance by each base class, non-plateau pairs, plateau pairs, and plateau-accented mixtures. Mixed cases use `N = 18..36`; the four base classes retain `N = 8..20`. The default 2000-case benchmark allocates 200 cases to every combination of class and knot spacing.

The benchmark panel exposes the manuscript random seed (`123456`), number of cases (`2000`), point-count range (`N = 8..20`), timing seed (`246810`), and measured timing repeats (`5`). At each of `N = 10, 100, 1000, 5000, 10000, 50000, 100000`, the default timing action evaluates six exact-function data sets and eight scalable discrete data sets. Each method receives one warm-up construction and five measured constructions per data set. The display reports the median and interquartile range across the 14 within-data-set medians. The public repository retains the deterministic generator and numerical evaluation code used by the manuscript.

The artifact exporter also reconstructs two deterministic motivation examples for each guard. The generated examples are reproduced from the fixed benchmark sequence, and the remaining example is the built-in Arc data. Each highlighted interval belongs to only one of the three active collections. The corresponding figure disables that guard alone while preserving the other two.

The deterministic stability export uses seed `314159265`. It applies horizontal and vertical scale factors from `1e-8` through `1e8`, large origin translations, ordinate reflection, combined affine transformations, and the constant-data branch. Separate trials cover `hmax/hmin = 1e4` and `1e8` and perturb both sides of numerically located activation boundaries. The export contains configuration summaries and one residual/certificate record per construction. It does not add observation noise and does not support a noise-robustness claim.

## Reproducibility

The app requires no build step. Open `index.html` directly or launch the version hosted by GitHub Pages. From the repository root, run `node tests/run_tests.cjs` for the deterministic regression suite. The scripts under `scripts/` reproduce the unrounded benchmark, solver-diagnostic, stability, timing, and parameter-validation records from the same inline implementation. Generated JSON is written under `build/` and is intentionally excluded from version control.
